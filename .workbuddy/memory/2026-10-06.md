# 2026-10-06 内核源码推送到 Gitee 远端备份

## 背景

## 关键发现（决定了推送策略）
- **`mofan0810/x-kernel` 是 `openkylin/x-kernel` 的完整 fork**，不是空仓库：
  共 **146 个 refs**（约 130 个分支 + 10 个 tag），含上游的 `debin/*`、`clk/*`、
  `GC-2603`、`codex/pr4-halt-poweroff-smp` 等开发分支。
- 它的 `main` = **`cea097dfde8d6a4b057e03152f9462008e3c1c5e`**，**与上游
  `openkylin/x-kernel` 的 main 完全相同**。
- ⚠️ **T490 的 `origin/main` 引用是 9 月抓取的 `39d1788`，而上游 main 已前进到
  `cea097d`** ⇒ 本地 main（基于 `39d1788`）与远端 main **不是 fast-forward 关系**。
- ⇒ **绝不能推 `main`**：non-FF 会被拒；若强推会把 fork 的 main 倒退、削掉上游
  这 13 天的新提交。**策略改为推新分支 + 自己的 tag。**

## 执行（本机中转，避免把凭据送到 T490）
凭据现状：**T490 既无 `~/.git-credentials` 也无 SSH 私钥**（`~/.ssh` 里只有
`authorized_keys`，是别人登录它用的）；**本机 Windows 有** `~/.git-credentials`
的 gitee 条目，但**未配 `credential.helper`**，需显式 `-c credential.helper=store`。

1. 本机裸克隆（只取 .git，5 MB；T490 工作树 28 GB 但 .git 仅 7 MB）：
   `git clone --bare ssh://mo@192.168.1.217/home/mo/x-kernel xk-bare.git`
2. `--dry-run` 验证认证与推送范围（**匿名 `ls-remote` 成功不代表凭据有效**，
   公开仓库匿名可读 —— 必须用 dry-run push 验）
3. 正式推送：
   ```
   git -c credential.helper=store push https://gitee.com/mofan0810/x-kernel.git \
     "refs/heads/codex/initial-round-single-process:refs/heads/t490-chromium-runtime" \
     refs/tags/basic-baseline-20260922 refs/tags/p0-drm-version-fix \
     refs/tags/v0.1-first-runnable refs/tags/v0.2-compat-p0p4
   ```

## 结果（已用 `ls-remote` 回读验证）
- `refs/heads/t490-chromium-runtime` = **`2a1b101`** ✅（含 39d1788 之后的全部 14 个提交）
- 4 个 tag 全部到位 ✅（`basic-baseline-20260922` / `p0-drm-version-fix` /
  `v0.1-first-runnable` / `v0.2-compat-p0p4`）
- `refs/heads/main` 仍 = `cea097d`，**与上游一致、未被破坏** ✅

⇒ 内核源码自此有第二份远端副本，风险等级下降。

## 复现要点
- Windows Git Bash 推 Gitee：`git -c credential.helper=store push <url> ...`，
  配 `GIT_TERMINAL_PROMPT=0` 防止非交互环境挂起。
- `git ls-remote` 对公开仓库匿名可读，**不能**用于验证凭据；验证要靠 dry-run push。
- annotated tag 在 `ls-remote` 里显示的是 **tag 对象 SHA**，带 `^{}` 后缀的行才是
  它指向的 commit（如 `c2fde2c…` 是 tag 对象，`c2eabd5…` 才是 commit）。

## 遗留

  ① 生成 T490 的 SSH 密钥并把公钥加到 Gitee 账号（最干净，一劳永逸）；
  ② 在 T490 配置 HTTPS 凭据（Gitee 用户名 + 私人令牌）。

## ⛔ 本日最重要的操作性教训：T490 跑构建必须显式带 `~/.cargo/bin`

**症状极易误判**：非交互 SSH 的 PATH 不含 `~/.cargo/bin` ⇒ `cargo`/`rustc` 落到系统自带的
