## 官方三页「整页全高」渲染（本轮新增工具）

**背景**：`scripts/testpage/reference/` 里的官方参考图只有 1280×800 单帧，`layout` 的
"6/6 通过"结论条在整页 y≈1450，参考图**看不到**；`interaction` 的参考图是未操作态（灰色结论条）。
需要一套能看全三页、且能演示"操作后绿灯态"的整页图。

**产出**（均在 `tmp/testpage-render/`，属可丢弃工作产物，未写入仓库）：
| 文件 | 内容 |
|---|---|
| `index.png` | index.html 整页，1280×819 |
| `interaction-wait.png` | interaction.html 未操作态，1280×890 |
| `interaction-done.png` | **自动操作后**（键入 `hello x-kernel` + 点 3 次 + 运行自检），全绿、结论条 `核心检查 6/6 全部通过`，1280×890 |
| `layout.png` | layout.html 整页，含 C5 斑马纹 / C6 对齐 / 结论表 C1–C6 全绿 / 结论条 `布局检查 6/6 全部通过`，1280×1589 |
| `render_pages.py` | 渲染脚本（可复用） |

**渲染管线（零第三方依赖）**：
1. Chrome `--headless=new --hide-scrollbars --force-device-scale-factor=1`
   `--virtual-time-budget=3000 --window-size=1280,1800 --screenshot=...`
2. 复用 `scripts/png2ppm.py` 的 `read_png()`（纯标准库 PNG 解码）逐行比对 body 背景
   `#f4f6f8`，从底部切掉纯背景行 + 留 30 px ⇒ 输出 `<tag>-crop.ppm`
3. 复用 `scripts/ppm2png.py` 转回 PNG（该脚本按源文件同名输出、**没有 `--out-file`**，
   故先生成 `<tag>-crop.png` 再改名）

**演示副本**：`interaction-demo.html` = interaction.html 末尾注入 60 ms 后自动键入 + 点击 + 运行自检的脚本。
**只在 tmp 生成，不写回 `scripts/testpage/`**（guest 侧仍用原始三页，判据不受影响）。

**踩坑**：`interaction-wait.png` 与 `interaction-done.png` 文件大小只差 276 B（48785 vs 48509），
**不能用文件大小判断操作是否生效** —— 灰底/绿底压缩率相近，必须看图。
