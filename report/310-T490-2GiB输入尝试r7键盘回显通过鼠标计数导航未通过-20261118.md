# T490 2 GiB Input R7：键盘回显通过，鼠标计数与导航未通过

## 结论

R7 首次把真实键盘输入回显通过到 2 GiB 默认多进程页面：自检 T1–T6 通过，`hello x-kernel` 在文本框和回显区同时显示，localized keyboard echo diff PASS。Tab 和 PageDown 每步新增了截图；两次 Tab 后自检完成，PageDown 后计数按钮和 CSS 链接进入视口。

真实鼠标仍未通过：step4 HMP 双击后计数仍为 0；继续点击 CSS 链接后截图仍显示 `interaction.html`，修正后的布局 strict gate 拒绝导航，缺 C1/C2/C3。真实事件 ledger 记录 20 个 QMP 键盘动作、5 次 HMP 点击、549 次 HMP 步进移动，但像素结果表明计数和导航没有发生。Input 继续计为 0/4，2 GiB 总分仍为 16/20。

R7 的 `round_rc=1` 来自输入 runner 对整个 QEMU 会话仍启用 `STRICT_GATE=1`：滚动后官方交互横幅离开视口，3 张 session 截图触发 `post_pass_fail`。R7 的 ready strict 和分项交互 gate 是分别判定的；我已将 runner 的全程截图 strict 关掉，保留 ready 和 interaction score gate 的严格判定，待 R8 验证该改动。
