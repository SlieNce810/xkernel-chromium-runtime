# T490 2 GiB 输入尝试 R20：第二个请求命中计数，CSS 导航仍失败

## 结论

R20 在 T490 上使用 2 GiB guest、AArch64 纯 TCG、Chromium 149 默认多进程运行。交互页在第 47 次 readiness 采样通过；JS 自检和键盘回显通过。正式 `mouse_counter_diff` 门禁仍未通过，因为 counter 阶段的 `after-mouse-click` 截图仍显示 0。随后用于 CSS 导航的 `(350,710)` 请求却让页面 counter 变为 2，证明这一请求在本轮的 HMP 路径状态下点击到了计数按钮。CSS 页面仍未打开，`mouse_navigation` strict gate 失败；Input 仍为 0/4，总分仍为 16/20。

这项证据区分了两个动作：第一次 counter 请求 `(250,540)` 后计数仍为 0；第二个 navigation 请求 `(350,710)` 后计数变为 2。完整门禁没有把第二阶段的计数变化当作第一阶段 counter gate 的通过，因此正式 score gate 保持失败。R21 将把 `(350,710)` 用作 counter 请求并保持 CSS 请求不变，先单变量复测这个在本轮点中按钮的坐标。
