R36 使用 baseline freeze r3 指定的正式路径 `/home/mo/x-kernel` 与 `/home/mo/x-kernel/images/pkg-installed.img`。kernel SHA-256 为 `51c4028594e4aff9fc5b9964c4294a2904621c93e84093ac711858c454aed284`，rootfs SHA-256 为 `bab5c9f5dbf1e4a910bab569635bb9e44fe38c3b8cea94ae8eae4ce3f7a9fdb1`。QEMU 实跑参数为 `-m 2g -smp 4 -cpu cortex-a76`、无 `-accel`、virtio GPU/keyboard/mouse；平台 dry-run 与实跑断言15/15通过。

## 结果

指定 HTML 在1550秒 ready deadline 内未通过 `official-index --strict`；QMP完成51次页面轮询，没有 reload或保持段。240秒周期截图是 Weston 背景，1440秒和 timeout 截图为空白。guest watchdog末段仍报 `weston=yes chrome=yes`，console未见 OOM 或 Browser/Weston退出。页面 driver 记录 `STABILITY_DRIVER_FAIL initial strict page gate timed out`；归一化和性能阶段均不构成PASS。

历史 evidence 287–289 在同一 kernel SHA 51c、同一2 GiB平台下记录了三个首页strict通过轮次。R36 表明冻结根当前仍有启动长尾/间歇性空白风险；正式三次冷启动验收不能仅引用历史通过项，应在默认2400秒 ready timeout下重新复核，并将R36失败计入故障分析。
