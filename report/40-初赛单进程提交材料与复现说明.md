本材料对应分支 `codex/initial-round-single-process` 和基线标签 `v0.1-single-initial`，范围固定为单进程 Chromium 主流程。多进程 renderer、zygote、多线程同步和决赛双窗口功能暂不纳入本分支的功能门禁。

## 可复现命令

在 T490 上执行：

```bash
cd /home/mo/xk6
ASSERT_PROFILE=official-index \
FIRST_SHOT=180 \
BASE_IMG=/home/mo/x-kernel/images/agentos-weston.img \
PKG_TARBALL=/home/mo/xk6/tmp/eudev-seatprobe-libinput-swiftshader-p31.tar.gz \
INJECT_AUTOSTART=1 STRICT_GATE=1 \
bash scripts/t490/t490_round.sh \
  single-initial-r5 720 60 autorun_single_initial.sh
```

轮次结束后，以下文件是初赛功能证据的核心：

- `console.log`：启动参数、首个导航、`SINGLE_GATE=1` 和 QEMU monitor 记录；
- `ppm-summary.txt`：官方 index 严格像素结果和相邻帧心跳；
- `screenshots/*.ppm`：原始 QEMU screendump；

- `build-manifest.txt`、`cmd.txt`、`env.txt`、`manifest.txt`：内核、镜像、页面和主机指纹。

## 兼容性缺口与补丁候选

当前应提交的缺口说明按“现象、最小复现、Linux 对照、影响、已有补丁/限制”组织，来源于：

- fd 表下界和 zygote fd 继承；
- `SCM_RIGHTS`、`SCM_CREDENTIALS`、`MSG_CMSG_CLOEXEC`；
- `ppoll_time64`；
- procfs 线程、状态、内存和 uptime 字段；
- `PR_SET_PDEATHSIG` 最小语义；
- Unix DGRAM/SEQPACKET 半关闭和凭据；
- TCP keepalive 选项；
- futex PI 未实现时返回 `EOPNOTSUPP`，使 musl 回退到普通 mutex；
- D-Bus session 请求 `RLIMIT_NOFILE=65536` 与当前固定 1024 fd 表容量不一致。

Wayland/Weston 不在本轮重写。最小静态协议探针在无 damage、带 damage、fullscreen 三个场景都收到 configure，证据见：

- [xdg-libwayland-r6](../evidence/2026-10-02_t490-xdg-libwayland-r6/console.log)
- [xdg-libwayland-r7](../evidence/2026-10-02_t490-xdg-libwayland-r7/console.log)
- [xdg-libwayland-r8](../evidence/2026-10-02_t490-xdg-libwayland-r8/console.log)

## 初赛与决赛范围

本提交包按初赛门禁整理：图形会话连续稳定至少 10 分钟、Chromium 创建窗口并显示指定 HTML、提交缺口与复现方法、提交可复现测量脚本和方法文档。

以下属于决赛阶段，保留为后续工作，不在本分支单进程初赛门禁中宣称通过：30 分钟稳定、每两分钟加载页面 10 次、至少两个窗口/标签页、完整键鼠/JavaScript/CSS 交互、renderer 多进程结构和 1.5 GiB 内存资格线。
