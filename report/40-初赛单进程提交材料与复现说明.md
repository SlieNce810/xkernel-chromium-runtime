## 可复现命令

在 T490 上执行：

下列命令使用仓库内已交付的 overlay，并用新场景名保存结果；不覆盖历史 r5。首次搭建请先按根 README 准备 `~/xk6` 与 `~/x-kernel`。

```bash
cd "$HOME/xk6"
ASSERT_PROFILE=official-index \
FIRST_SHOT=180 \
BASE_IMG="$HOME/x-kernel/images/agentos-weston.img" \
PKG_TARBALL="$PWD/guest-overlays/eudev-seatprobe-libinput-swiftshader-p31.tar.gz" \
SINGLE_HOLD_VALUE=600 \
INJECT_AUTOSTART=1 STRICT_GATE=1 \
bash scripts/t490/t490_round.sh \
  "verify-initial-$(date +%H%M%S)" 900 60 autorun_single_initial.sh
```

轮次结束后，以下文件是初赛功能证据的核心：

- `console.log`：启动参数、首个导航、`SINGLE_GATE=1` 和 QEMU monitor 记录；
- `ppm-summary.txt`：官方 index 严格像素结果和相邻帧心跳；
- `screenshots/*.ppm`：原始 QEMU screendump；
- `guest/_root_single-initial.log`、`guest/_root_single-initial.csv`（若 round 收尾遇到 QEMU 退出竞态，则同样内容保留在 `console.log` 的 `[single]`/`METRICS` 段）；
- `build-manifest.txt`、`cmd.txt`、`env.txt`、`manifest.txt`：内核、镜像、页面和主机指纹。

## 兼容性缺口与补丁候选

当前缺口说明应按“现象、最小复现、Linux 对照、影响、已有补丁/限制”组织。**2026-10-05 口径收敛**：合并同类项并补入 virtio-input 消费缺口，整理为以下 8 条。赛题是“最多计 8 个缺口”，额外条目不计分，并非禁止记录更多缺口。目前本节为条目索引，逐条探针、Linux/guest 输出及补丁映射还需整理成可直接复核的附件，不能仅凭这份清单宣称五要素已经齐全：

1. fd 表下界 + zygote fd 继承语义；
2. Unix 套接字 ancillary（`SCM_RIGHTS`/`SCM_CREDENTIALS`/`MSG_CMSG_CLOEXEC`）与 Unix DGRAM/SEQPACKET 半关闭和凭据（两条合一）；
3. `ppoll_time64` 分派；
4. procfs 线程、状态、内存和 uptime 字段；
5. `PR_SET_PDEATHSIG` 最小语义；
6. TCP keepalive 选项；
7. futex PI 未实现时返回 `EOPNOTSUPP`（musl 回退普通 mutex）与 D-Bus session 请求 `RLIMIT_NOFILE=65536` vs 固定 1024 fd 表容量（用户态配套，两条合一）；
8. **virtio-input 事件消费链未打通**（QMP 层注入成功但内核无事件消费，见 report/44）；

Wayland/Weston 不在本轮重写。最小静态协议探针在无 damage、带 damage、fullscreen 三个场景都收到 configure，证据见：

- [xdg-libwayland-r7](../evidence/2026-10-02_t490-xdg-libwayland-r7/console.log)
