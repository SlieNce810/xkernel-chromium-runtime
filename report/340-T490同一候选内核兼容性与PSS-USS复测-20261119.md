# T490 同一候选内核兼容性与 PSS/USS 复测（2026-11-19）

## 结果

在 Chromium 首页集成轮使用的同一候选内核二进制 SHA-256 `fa02114ae8058e3da43942ec614f098f53a2b5b41b20181b7728f7992c983e48` 上，AArch64 2 GiB pure-TCG guest 的 focused bundle 返回 0：

- `timerfd` 4/4、`inotify` 7/7，合计 11/11；包括 one-shot 到期、创建事件读取及 watch removal。
- SCM_RIGHTS short-read 6/6；fd 在首次 1-byte `recvmsg` 到达，不在后续读取重复，100-byte payload 完整。
- RSS/PSS/USS memory probe 在匿名页、MAP_PRIVATE、MAP_SHARED、fork/COW 和 unmap 阶段均输出数值。
- QEMU 实际运行 303.3 秒；平台检查 15/15，guest `-m 2g`、`-smp 4`、`-cpu cortex-a76`、无 `-accel`。

这轮把之前不同构建 SHA 的 focused probes 补到 Chromium 集成轮的精确二进制 SHA。相同 SHA 的首页集成和进程链 gate 见 [report 339](339-Chromium149候选内核首页与进程链复核-20261119.md)。

## RSS/PSS/USS 原始阶段值（kB）

| 阶段 | RSS | PSS | USS | Shared |
|---|---:|---:|---:|---:|
| baseline | 128 | 128 | 128 | 0 |
| anon touched | 256 | 256 | 256 | 0 |
| file-private touched | 384 | 384 | 384 | 0 |
| file-shared touched | 512 | 384 | 256 | 256 |
| child after child COW | 228 | 123 | 20 | 208 |
| parent before parent COW | 512 | 281 | 52 | 460 |
| parent after parent COW | 512 | 285 | 60 | 452 |
| child after parent COW | 228 | 123 | 20 | 208 |
| after unmap | 128 | 128 | 128 | 0 |

`file_shared_touched` 的 RSS +128 kB、PSS 不变、USS −128 kB、Shared +256 kB；unmap 后 RSS/PSS/USS 回到 baseline，VmHWM 保留 512 kB。数值与 T490 native Linux reference 的主要 file-shared/COW/unmap 变化一致。

## 复现和边界

- 命令、guest console、平台检查、环境、六张截图判据、运行清单及 host launcher log 在 [本轮证据包](../evidence/2026-11-19_t490-codex-2026-11-19-fileprivate-compat-r2/)；原始 PPM 留在 T490，只提交 SHA-256 清单。
- Linux native 对照见 [report 336](336-T490-native-Linux-procfs-memory-parser-r2-20261119.md)，首次 MAP_PRIVATE 分布差异及修复链见 [report 337](337-x-kernel-PSS-USS候选采样与MAP_PRIVATE差异-20261119.md) 和 [report 338](338-MAP_PRIVATE页缓存共享与PSS-USS-guest复测-20261119.md)。
- 这是小型单进程/父子进程兼容探针，不是 Chromium 进程树 1 Hz 采样，也不是页面完成后 60 秒的进程峰值；它不能填四项性能样本或 1.5 GB 资格线数据。
- Chromium startup 的 7 次 `inotify_add_watch NotFound` 已通过路径诊断归类为可选 policy/time-zone 组件 watch，详见 [report 341](341-Chromium149-inotify可选路径NotFound分类-20261119.md)。C probe 证明同一 hash 的 inotify named create ABI 可用。
