# T490 2 GiB Input R5：ready timeout，输入 driver 未开始

## 结论

R5 在 2 GiB 默认多进程正式参数下未能通过 `official-interaction` 页面 ready gate。达到 `READY_TIMEOUT=2000` 后，188 次、每 10 秒一次的采样仍未检测到官方横幅和交互表结构；sample 127 与最终 sample 188 的 PPM SHA-256 完全相同，画面为纯白。真实输入 driver 没有启动，因此本轮没有键盘、鼠标、Tab/Enter、焦点或计数控件结论，Input 仍为 0/4，2 GiB 浏览器功能总分仍为 16/20。

T490 的会话收尾清单记录 `actual_sec=2042.9`，纯 TCG 浏览器 session gate 失败（27 张 session 截图均是启动期未通过帧）。ready timeout 后我通过 QMP `quit` 正常关闭 QEMU；QMP ledger 收到 host-quit 的 SHUTDOWN 回执。统一入口本地 SSH 通道又未返回，记录为外层 acceptance `rc=255`；该状态与 T490 的 `ready.log`、`ppm-summary.txt` 和 QEMU manifest 分开呈现。

## 判据结果

| 判据 | 结果 |
|---|---|
| 页面 ready | FAIL，`PAGE_READY_TIMEOUT`，188 次采样；最后失败项 `official_banner`、`interaction_checks_table` |
| Chromium 进程 | console 持续记录 Browser 和一个 renderer 候选；轻量 `ps|awk` 的 Renderer PID 逐样本变化不能单独证明进程崩溃 |
| 键鼠输入 | NOT RUN；`input driver` 未开始 |
