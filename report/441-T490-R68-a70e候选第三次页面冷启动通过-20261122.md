# T490 R68：a70e compatibility 候选第三次页面 cold-start 通过

R68 使用 R65/R66 同一内核二进制 SHA `a70ecb4a34910f56c31d677f1b27d3a25088b94dc2fc82ba13b33544f34e3c1f`，所有会话参数一致：2 GiB AArch64 pure TCG、Chromium 149.0.7827.53、2400 秒首屏期限、一次真实 Ctrl+R、420 秒诊断保持。实际 QEMU `-kernel` 路径和 expected SHA 经现场核对匹配。

initial 与 reload strict 页面均通过 7/7；driver 记录 `pass=1 duration=420.0 reloads=1/1`，normalizer 306/306 PASS，0 修复。guest 240 秒暖机截图为白帧，540 秒周期截图严格通过。Weston、Chromium 和 renderer 在保持窗口存活，无 Wayland reset。完整命令、环境、证据和原始 PPM 哈希见 [R68 evidence](../evidence/2026-11-22_t490-r68-r64-compat-cold05/README.md)。

R65、R66、R68 是同一 a70e binary SHA 的三次独立诊断 cold-start 通过；R67 仍是同 hash 的 2400 秒首屏失败。因此三次通过口径已满足，但启动间歇性没有消失，不能把它写成每次都稳定。正式 30 分钟稳定性仍待在 c80 上运行；R65–R68 均关闭性能采集，四项指标 before/after 批次尚未开始。
