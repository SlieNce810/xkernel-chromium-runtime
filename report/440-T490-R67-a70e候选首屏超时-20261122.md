# T490 R67：a70e compatibility 候选首屏超时

R67 是 c80/a70e 候选在相同参数下的第三次独立 Chromium cold-start：kernel SHA `a70ecb4a34910f56c31d677f1b27d3a25088b94dc2fc82ba13b33544f34e3c1f`、2 GiB、AArch64 pure TCG、Chromium 149.0.7827.53、2400 秒 readiness timeout、一次真实重载计划、420 秒诊断保持计划。

结果与 R65/R66 不同。2400 秒内未达到 strict official-index 页面；8 张周期截图与 initial-timeout PPM 均白屏，严格 1/7。Chromium、Weston 和 3 个 renderer 在期限末仍存活，normalizer 1103/1103 PASS、0 修复；driver 明确报告首屏 gate timeout，未发生重载/保持。详细原始数据和哈希见 [R67 evidence](../evidence/2026-11-22_t490-r67-r64-compat-cold04/README.md)。

R65、R66 的同 hash 参数冷启动通过，R67 同 hash 2400 秒超时，说明 a70e 的启动仍有长尾/间歇失败；不能依据两次通过宣称三次独立成功。该诊断轮未采集性能指标，且不是 formal 30 分钟 gate。正式稳定性和性能批次仍待修复启动长尾后重跑。
