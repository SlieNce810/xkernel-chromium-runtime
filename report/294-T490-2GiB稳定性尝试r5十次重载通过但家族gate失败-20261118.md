# T490 · 2 GiB 稳定性尝试 r5（2026-11-18，保持与页面重载通过，Renderer 家族 gate 失败）

## 结果

r5 完成了 1,805 秒保持、10/10 次真实 Ctrl+R strict PASS，且没有重现 r4 的页面无响应。但正式稳定性 gate 仍未通过：严格事件复核拒绝 8 条 hold 窗口 liveness 记录，其中 7 条的家族角色缺少 Zygote 子进程/Renderer，1 条完整快照年龄为 35.026 秒，超过 35 秒上限。该轮可证明页面重载和保持时长通过，不能证明整个窗口内 Renderer 家族持续存活。

## 失败定位

严格规范化器没有修复任何家族样本，报告 8 条不完整记录：`goal2g-stability-r5:110`、`:119`、`:127`、`:139`、`:197`、`:222` 和 `:574` 的角色分别只有 Browser/BrowserChild 或 Browser；`:537` 虽包含家族角色，但对应完整快照年龄为 35.026 秒。离线 gate 使用这些严格事件后，在 liveness sample 1 报 Browser/Zygote/Renderer 家族缺失。runner 因规范化失败跳过正式 gate，并写出 `STABILITY_GATE_SKIPPED`，结果仍是 FAIL。

本轮 host 命令设置了 `MP_FAMILY_DIAGNOSTICS=1`，但实际 guest console 中 `MP_FAMILY_SKIP=0`。r5 使用的 `t490_round.sh` 没有把该环境变量注入 guest autorun，因此本轮没有得到候选 PID 被排除原因。已经在下一轮脚本中加上 `__MP_FAMILY_DIAGNOSTICS__` 注入占位符、0/1 参数校验和回归断言；r6 将先验哈希并检查 console 中实际出现 skip reason，再运行。

r4 的第六次页面挂起在 r5 没有重现，十次页面加载全部通过。进程家族证据仍有间断，下一步要通过注入后的 `MP_FAMILY_SKIP` 诊断标记判断候选 PID 是进程目录消失、starttime 不匹配、PPID 变化还是 Zygote 父进程缺失。不会把早期完整快照复用为后续 liveness 的 Renderer 存活证明。
