# Chromium 149 候选内核首页集成与进程链复核（2026-11-19）

## 结论

T490 上使用隔离兼容补丁内核，在 2 GiB、纯 TCG、Chromium 149 默认多进程模式下运行指定首页 1100 秒。QEMU 返回码为 0；16 张 1280×800 截图中 11 张通过 `official-index --strict`，首次通过点为 guest 541 秒，后续至最终截图持续通过。页面可见内容、颜色块、表格和布局匹配指定 HTML。

首页 gate 为 PASS。原运行的进程结构 gate 先返回 1；复核发现串口首条 Browser `MP_EVENT` 被 ANSI 清理器误删。修正归一化器后，使用同一份原始 console 离线重跑严格 gate，得到 11/11 个有效事件和 4/4 分的 Browser → Zygote → Renderer 父链。原失败记录保留在浏览器运行证据，复核结果单独存放，没有修改或重跑原会话。

Chromium console 显示 157 条 `SCM_RIGHTS` fd 接收记录，涵盖 socket、V8 snapshot、临时文件和 Wayland cursor 等描述符；本轮 Browser、Zygote、Renderer IPC 持续运行且指定页面严格通过。此前修复版 C guest 短读探针为 6/6，Knet stream 单测为 24/24，见 [report 334](334-SCM_RIGHTS修复版guest短读复测-20261119.md)；之后在本轮相同内核 SHA 上又复跑为 6/6，见 [report 340](340-T490同一候选内核兼容性与PSS-USS复测-20261119.md)。浏览器集成结果补充说明 Mojo 路径可运行，但不替代短读边界 C 探针。

## 结论边界

这是一个候选内核 HTML 集成轮，不是三次冷启动、六项 20/20、真实键鼠、30 分钟稳定性或十次 reload 的复验。它有逐 syscall 诊断输出（console 约 36.9 MB），不作为性能样本；Browser main loop ready、Renderer ready 同钟事件，以及 1 Hz 进程树 RSS/PSS/USS 采样仍缺。inotify `NotFound` 的具体路径也未解析。
