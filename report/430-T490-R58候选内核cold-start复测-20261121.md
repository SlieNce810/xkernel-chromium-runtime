# T490 R58 候选内核冷启动复测

## 结论

R58 是有效的 no-direct-PTE、`LOG_LEVEL_ERROR` 候选冷启动诊断样本。稳定性入口显式设置候选 `KERNEL_DIR`，并以预期 SHA-256 作启动前约束；实际运行 QEMU 命令中的 `-kernel` 路径也指向候选 worktree。

配置为 2 GiB AArch64 纯 TCG、Chromium 149.0.7827.53、官方 index 页面、2400 秒页面就绪期限、一次真实 Ctrl+R 重载和 420 秒诊断保持。候选内核 SHA-256 为 `c78ecd57fb47b8269ebecf0a4e99ee5d9f85648e01703726eee7af88ad017a67`。首张 guest 240 秒周期截图仍为白屏；guest 540 秒截图通过官方 index 严格判据 7/7。稳定性驱动保存的初始及重载 PPM 均通过严格判据，驱动结果为 `pass=1 duration=420.0 reloads=1/1`。事件归一化 242/242 PASS，0 修复。

这是冷启动与短保持的成功诊断样本，不能替代 30 分钟正式稳定性门槛。截图时点 540 秒只是定时采样得到的可见页面上界，不是启动或首帧的精确延迟。内存采样、生命周期 preload、guest clock sync 都关闭，因此不产生四项性能统计数据。
