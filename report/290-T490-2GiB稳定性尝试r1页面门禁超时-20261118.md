# T490 · 2 GiB 稳定性尝试 r1（2026-11-18，失败记录）

## 结果

本轮在平台默认 guest 2 GiB、AArch64 QEMU 纯 TCG 下启动了专用稳定性 runner。driver 等待初始 official-index strict PASS 到 readiness deadline，期间 72 张截图全部未通过；driver 记录 `STABILITY_DRIVER_FAIL initial strict page gate timed out`，随后以 QMP 正常退出 QEMU。

| 项目 | 实测 |
|---|---|
| T490 | ThinkPad T490，10.249.11.192，Intel Core i7-8665U，Ubuntu 26.04.1 LTS |
| 命令 | `bash scripts/t490/run_stability_round_mp.sh goal2g-stability-r1 4200 30`；取消 `PLAT_MEM_OVERRIDE` |
| QEMU | 10.2.1，AArch64，纯 TCG，4 vCPU，guest `-m 2g` |
| Chromium | 149.0.7827.53，Wayland/SwiftShader，`--ipc-connection-timeout=600`、`--js-flags=--jitless`、诊断模式 `--no-sandbox` |
| 页面判据 | 72 张 official-index 截图；严格集 72/72 失败，`page_fail=1`，最终帧未通过 |
| 初始页面 | 没有 strict PASS；`page_ready` 事件不存在，真实导航/重载数为 0 |
| QEMU 退出 | readiness 超时后正常收尾，`SESSION END (exit=0)`；`STABILITY_ROUND_RC=0` 只表示 QEMU 收尾，不表示稳定性通过 |
| gate | `STABILITY_DRIVER_RC=1`、`STABILITY_GATE_RC=1`；本轮不能计入 30 分钟稳定性通过 |

guest watchdog 在运行中多次记录 Weston=yes、chrome=yes；console 有 `FileURLLoader::Start`，但没有 DocumentLoader/DidCommitNavigation，official-index 像素集持续失败。截图在 guest 会话约 240 至 2385 秒按 30 秒间隔记录。

## 处理

稳定性计时必须从初始 strict 页面通过之后开始；r1 没有到达该条件，所以没有生成任何有效稳定性时长或 reload 样本。修正后的 r2 将改用轻量多进程观察路径：保留 Browser/Weston watchdog，每 5 秒输出 Browser、Zygote、Renderer 家族快照，并把 ledger 模式关闭以减少 renderer bootstrap 期间的 procfs 读取。这个候选修正尚待下一轮 T490 实测。
