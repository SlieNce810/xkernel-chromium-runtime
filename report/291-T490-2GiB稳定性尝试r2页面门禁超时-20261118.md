# T490 · 2 GiB 稳定性尝试 r2（2026-11-18，失败记录）

## 结果

r2 使用轻量 observer6 与每 5 秒进程家族快照，保持 guest 2 GiB、AArch64 QEMU 纯 TCG。ready timeout 到期时，指定 official-index 首页仍未通过 strict 判据；QEMU 正常退出。driver 未进入稳定性计时，也没有发送十次重载。

| 项目 | 实测 |
|---|---|
| T490 | ThinkPad T490，10.249.11.192，Intel Core i7-8665U，Ubuntu 26.04.1 LTS |
| 命令 | `bash scripts/t490/run_stability_round_mp.sh goal2g-stability-r2 4200 30`；取消 `PLAT_MEM_OVERRIDE` |
| QEMU | 10.2.1，AArch64，纯 TCG，4 vCPU，guest `-m 2g` |
| observer | `autorun_mp_score_observe6.sh`，MP_LEDGER=0；`MP_FAMILY` 每 5 秒记录父子进程候选，Watchdog 记录 Weston/Browser |
| readiness | 2400 秒 deadline；`page_ready` 缺失，初始 strict 页面超时 |
| 页面 gate | 共 72 张周期截图，72/72 严格集失败；`page_fail=1`、最终帧未通过 |
| reload / stability | 0 次有效 reload、0 秒稳定 hold；不能计为稳定性 PASS |
| 结果码 | `STABILITY_DRIVER_RC=1`、`STABILITY_ROUND_RC=0`、`STABILITY_GATE_RC=1`；QEMU 正常退出表示会话收尾成功，不表示 gate 通过 |

期间 Watchdog 多次记录 Weston=yes、chrome=yes，family 快照包含 Browser、Zygote 子进程和 Zygote 子进程候选；console 中 FileURLLoader 启动，但无 DocumentLoader/DidCommitNavigation。最后一张截图仍是白屏。轻量监控没有恢复页面提交，因此 r3 将以同一 observer/采样条件降低初始页 QMP screendump 频率，测试它是否影响 renderer bootstrap。

## 结论边界

本轮没有稳定性样本，也没有任何有效 reload。它只证明这组启动/观测条件下，页面 readiness 在 2400 秒内失败；不能用 30 分钟存活、页签加载或性能指标作结论。r1/r2 均作为失败轮保留。
