# T490 R33 sampler-off 重复页面控制（2026-11-21）

## 结果

R33 完全重复 R31 的最小页面配置：R27 kernel、2 GiB AArch64 pure TCG、Chromium 149、Wayland、默认多进程、virtio 键鼠；memory sampler、lifecycle preload 与 guest clock-sync 关闭，family watchdog 30秒。官方首页 strict 通过，QMP elapsed `465692.398591 ms`；1/1真实 Ctrl+R 重载和420秒保持通过，结束时 Weston/Chrome 存活。最终截图显示指定测试页完整渲染。

240秒周期截图仍是 Weston 背景；随后页面 strict 在约465.692秒通过。由于 guest clock-sync 关闭，这个 elapsed 只保留为 T490 host monotonic 的轮内诊断值，不能用于 guest-clock 性能 CSV。稳定性事件 normalizer 另报 `complete family snapshot is stale (age_s=38.034, limit_s=35)`，所以本轮不构成稳定性总验收 PASS。

## 对R30/R32失败的定位范围

R31与R33两次 sampler-off 最小页面轮均通过；R32 sampler-only 与 R30 sampler+preload 轮均出现 strict 超时和空白画面。这个对照支持“1 Hz sampler 负载可能增加页面渲染风险”的假设，但目前 sampler-on只有两次相关失败，且之前R26/R27/R29在同类采样下曾通过，结果有明显波动，**不能认定 sampler 是唯一原因**。renderer-ready/first-frame hook仍缺失，下一步需继续定位 Browser→Renderer IPC、画面提交和采样并发等待链。
