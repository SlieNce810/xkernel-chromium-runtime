# T490 2 GiB 输入尝试 R12：键盘通过，修正坐标后鼠标仍未生效

## 结论

R12 在 `EVDEV_PROBE=0` 条件下于第 47 次采样通过 `official-interaction` ready。动态 keyboard echo 轮询第一次 10 秒采样即检测到输入区域变化；JS 自检 6/6，`keyboard_echo_diff` 与 Keyboard 子 gate 均 PASS。

鼠标计数专用 ROI 保持 FAIL：计数仍为 0。R11 根据相对指针截图把计数与导航目标调整为 `(247,607)`、`(292,638)`；R12 点击后截图中的光标仍处于页面下缘，计数按钮和 CSS 链接均未触发。鼠标导航 gate 的 `official-layout` strict 检查仍失败，导航后画面还是 interaction 页。R11 的光标观测只用于估算，本轮结果说明固定比例补偿没有解决落点问题；下一轮将减小相对移动步幅并放慢事件节奏，重新实测实际光标位置。

本轮共记录 20 个 QMP 键盘动作、5 次 HMP 点击和 453 次相对移动。由于 `EVDEV_PROBE=0`，没有底层 event node 事件记录。Input 仍为 0/4，2 GiB 总分保持 16/20。
