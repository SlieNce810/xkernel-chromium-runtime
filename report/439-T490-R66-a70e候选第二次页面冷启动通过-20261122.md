# T490 R66：a70e compatibility 候选第二次 Chromium cold-start 通过

R66 在 R65 同一内核二进制 SHA `a70ecb4a34910f56c31d677f1b27d3a25088b94dc2fc82ba13b33544f34e3c1f` 上，采用相同的 2 GiB AArch64 pure-TCG Chromium 149 参数、2400 秒 page deadline、一次真实 Ctrl+R 和 420 秒保持。实际 QEMU kernel path 与预期 SHA 一致。

稳定性驱动捕获的初始及重载画面均通过官方 index 7/7，`pass=1 duration=420.0 reloads=1/1`；normalizer 306/306 PASS，0 修复。guest 240 秒周期截图是暖机白帧，guest 540 秒周期截图严格通过。Weston、Chromium 和 renderer 进程在保持阶段持续存活；无 Wayland reset。

R66 与 R65 组成同一 `a70ecb4a…` binary hash 的两次短诊断 cold-start/reload 通过，R63 的 `12c0e795…` 构建 hash 曾在同一 tracked diff/config 下发生 Wayland reset。该对比提示构建产物/启动存在差异，但不能推断确定原因。R65/R66 都不是正式 30 分钟稳定性验收，未启用性能采样。完整材料见 [R66 evidence](../evidence/2026-11-22_t490-r66-r64-compat-cold03/README.md)。
