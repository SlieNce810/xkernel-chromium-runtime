# T490 R30 默认多进程首页 strict 超时与空白屏（2026-11-21）

## 结果

R30 使用 R27 kernel（SHA-256 `95db6f57…de34db`）、T490 2 GiB AArch64 pure TCG、Chromium 149.0.7827.53、5秒 role 重检、1 Hz 900秒内存 sampler 和 lifecycle preload。QMP 在1550秒首页 deadline 内没有 strict PASS；稳定性 driver 记录 `initial strict page gate timed out`，结束结果为失败。QMP 1440秒截图和 timeout 截图均为纯白；240秒周期截图仍是 Weston 背景。

Guest watchdog 在末段持续报告 `weston=yes chrome=yes`，没有 OOM、Browser 或 Weston 退出标记。Lifecycle probe 捕获了 Browser main-loop wait、file URL 导航 open 和5个 Zygote fork boundary；没有 `renderer_ready` 或 `first_valid_frame`。采集器 summary 为 `valid=false`，报告缺少 passing page、renderer-ready、first-frame。

## 采样结果

内存串口 bundle 本身完整导出并解包（135 chunks，tar 283,648字节），但 sampler `FAIL`：239 sample IDs、246 missed、1,500行、310错误；process-tree unavailable 41、bulk unavailable 64、incomplete 64、overrun 141。QMP 页面未通过，采样窗口也没有覆盖“页面完成后至少60秒”这一口径，所以 RSS/PSS/USS 峰值不能作为有效峰值。

## 当前判断与最小复现

R30 与相邻 R26/R27/R29 使用同一页面与 kernel，但页面时序出现长尾并在 deadline 内未渲染。R30仍运行了 preload 与完整内存采样；仅凭此轮无法判断空白屏来自 Chromium renderer/图形链路、采样负载或偶发 TCG 调度。后续已安排一次 sampler/preload 均关闭的页面轮，保留默认多进程、Wayland、virtio 输入和 strict 截图，隔离观测负载。

R30 页面失败已计入异常，不计入稳定性 PASS 或任何性能统计。原始周期和 timeout PPM 留在T490，仓库提供 PNG 与 [PPM哈希索引](../evidence/_ppm-sha256-r30-role-recheck-900s.txt)；完整console、QMP、过程/lifecycle事件、采样错误和哈希清单见 [R30 evidence](../evidence/2026-11-21_t490-r30-role-recheck-900s/)。
