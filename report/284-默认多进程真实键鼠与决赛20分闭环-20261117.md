## 键盘与鼠标证据

可重算输入 evidence：[2026-11-17_t490-interaction-hmp-input-supplement-r1](../evidence/2026-11-17_t490-interaction-hmp-input-supplement-r1)。包内包括：

- `before-keyboard-echo.ppm`、`keyboard-echo-after.ppm`：文本框与回显区 ROI 差异通过，真实输入内容为 `hello x-kernel`；
- `mouse-counter-before.ppm`、`mouse-counter-after.ppm`：按钮前后 180 个像素变化，计数由 0 变为 1；
- `mouse-layout-destination.ppm`：真实鼠标点击赛题链接后到达 CSS 布局页，结论条 `布局检查 6/6 全部通过`；
- `interaction-events.jsonl`：真实 QMP `send-key`、virtio mouse HMP `mouse_move/mouse_button` 命令及事件回执；
- `interaction-score-gate.json`：JavaScript、键盘 ROI、鼠标计数、导航及真实输入事件全部通过；
- `score20-status.json`：六项决赛浏览器评分合计 20/20。

可查看 PNG 与原始 PPM SHA-256 索引见 [score20 review bundle](../evidence/2026-11-17_t490-score20-review/)。原始 PPM 仍按 T490 取证约定保留在源 evidence 目录/主机上；review bundle 中的 PNG 是由这些 PPM 转换出的查看图。

键盘输入使用 QMP `send-key`；鼠标使用 HMP 指针移动和按键。x-kernel 当前 QEMU 运行形态的 virtio-input 设备匿名，
QMP `input-send-event` 会返回成功但没有把键鼠事件送进 Weston；尝试给设备添加 QEMU id 会导致当前 QEMU 的 QOM
查找路径 SIGABRT。我们保留匿名设备组合，并使用 HMP 输入路径。eventdemo 与 Chromium 的实际截图分别证明事件到达
Wayland client 和页面控件，页面行为不是 DOM 注入或 CDP 代替。

## 当前原目标剩余门禁

20/20 只覆盖决赛浏览器功能分，不代表多进程浏览器架构的所有原始目标均完成。renderer 仍以 `--no-sandbox` 诊断模式
运行，原生 sandbox gate 尚未通过；30 分钟稳定性、真实 guest RSS/PSS/USS、5 次纯 TCG 性能统计和 before/after 归因也仍需完成。

按原始目标继续时，下一步应让 renderer 在默认多进程下完成原生 sandbox 初始化，并通过文件、socket、fd 和 syscall
负向测试；这项通过后再做稳定性、内存、性能和一键现场验收。
