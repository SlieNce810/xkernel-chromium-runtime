# T490 进程树采样 smoke 原始数据回收 R14（2026-11-20）

## 结论范围

R14 是 R13 `/proc` 实现 smoke 的证据补强轮，不启动 Weston 或 Chromium，也不计入六项功能、稳定性或四指标正式性能统计。它在 T490、AArch64、2 GiB、纯 TCG 上重复运行短 guest smoke，并把完整 CSV 与生命周期事件输出到原始串口日志，再由仓库提取器校验并落盘。guest 返回 `PROC_TREE_SMOKE_PASS`，`missed=0`，保存了完整 16 行内存记录和 4 条生命周期事件。

证据目录：[evidence/2026-11-20_t490-procfs-bulk-raw](../evidence/2026-11-20_t490-procfs-bulk-raw/)。未经处理的串口原文是 `console.log`；提取文件位于 `smoke-export/`，提取摘要记录原 console SHA-256 `dc2dcd6efce1281078ba6db6f62d68ae95d06c03c5cf8d9931749e9b8ba3bac9`。

## 原始数据和判据

客体输出为：

```text
PROC_TREE_SAMPLER_RESULT samples=8 processes=2 missed=0 source=procfs-tree-smaps_rollup duration_ms=7017
PROC_TREE_SMOKE sample_rows=16 processes_started=2 memory_errors=0 bad_values=0 start_time_count=2 bad_start_times=0
PROC_TREE_SMOKE_PASS
```

`smoke-export/memory-samples.csv` 保存 8 个连续 sample ID，每个 sample 包含 root PID 5 与 child PID 11 两行；RSS/PSS/USS 均为正数。root 进程身份 `5-145` 与 `/proc/5/stat` field 22 的 `145` ticks 一致，child 身份为 `11-176`。`smoke-export/lifecycle-events.jsonl` 保留 browser-launch 请求、root/child 创建和 sampling-finished 事件。root 的标准 `/proc/5/smaps_rollup` 输出为 RSS 588 kB、PSS 334 kB、USS 152 kB、Shared 436 kB。

复现和提取命令：

```bash

python3 scripts/t490/extract_proc_tree_smoke.py   evidence/2026-11-20_t490-procfs-bulk-raw/console.log   --run-id proc-tree-smoke-01   --out-dir evidence/2026-11-20_t490-procfs-bulk-raw/smoke-export
```

提取器校验 CSV 行数、列、时钟域、sample ID、PID/PPID 身份、RSS/PSS/USS 正数、进程起始 tick、事件顺序、`missed=0`、采样来源和 root `smaps_rollup` 字段。`test_extract_proc_tree_smoke.py` 5/5 通过，覆盖成功提取、缺行、零 starttime、重复内存行和缺生命周期事件。

R13 时曾尝试把 `/tmp` 输出复制到 guest `/root` 后由 `pull_guest_logs.sh` 读取；R14 停机后确认这些文件没有落在 QEMU 磁盘镜像中。采样 CSV 与事件现已通过原始串口日志完整保存，后续复现直接使用带标记的 console 提取流程；没有保留通用日志回收器的无效扩展。
