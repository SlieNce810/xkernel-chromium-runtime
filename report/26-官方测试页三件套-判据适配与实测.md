## 3. 判据失配实测：`legacy` 档在官方页上的表现

用旧的 9 条谓词（锚在自建页 `local-check.html` 的 CSS 上）直接判官方页：

```
index @1280x800        严格集 1/7 通过
失败 = banner_c8102e, swatches_3channels, swatches_left_to_right,
       swatches_same_row, checkerboard_24px, table_borders
```

两类问题，第二类比第一类危险得多：

1. **假阴性（可预期）**：`#c8102e` banner、120×72 三原色块、24px 黑白棋盘、`#444` 表格线
   —— 官方页里根本不存在这些特征。
2. **假阳性（危险）**：唯一的通过项 `js_executed_green_text` 是**错的**。
   `index.html` 是无脚本静态页，却被判成"JS 已执行"，因为它把**绿色块 `#2da44e`**
   （45,164,78）算进了 `detect_js_green` 的区间超集
   （条件只有 `r≤189, g∈[96,214], b≤200` 且 `g>r+25 且 g>b+25`）。实测误报 13614 px。

> 这正是 M2 那句"未验证的门禁比没门禁更危险"的现场：如果继续用 legacy 档跑官方页，
> 我们会得到"页面没渲染"的错误结论，同时在一张纯静态图上得到"JS 正常"的错误绿灯。

## 4. 官方页判据（`--profile official-*`）

常量全部来自第 2 节的**屏上实测**，不是从 CSS 反推。设计上沿用两条既有教训：

- **同色元素先分带再判形状**：`index` 页的 `#17456b` 同时是 banner、正文 SVG 的 rect、
  按钮底色，整体 bbox 是 848×692 —— 不限制在顶部 30% 内就完全不能当 banner 判据。
- **尺度无关优先**：内容宽度被 CSS 的 `max-width:880` 截断，1280 下表格线只有屏宽的
  0.64 倍。因此表格判据判的是"**线长自相等 + 等间距自洽**"，而不是"线长 ≥ 0.28·W"
  （后者实测在 1280 的画幅上会 0 命中）。

| 谓词 | 组 | 实测依据（正 / 负） |
|---|---|---|
| `official_banner` | core | 正 608×84 / 848×84；白图为 0 |
| `verdict_fail_absent` | core | 正 0 px / 37 px；注入 `#ffebe9`+`#c93c37` 后立刻翻红 |
| `index_blocks_shape/same_row/equal_width/order` | core | 正 4 块 131×64 同行等宽；涂白一块 / 黄块下移 25px 后对应项失败 |
| `index_table_rules` | viewport(min_h=420) | 正 5 条 ×31（640）/ 6 条 ×31（1280）；抹掉中段 3 条后失败 |
| `index_is_static`（反向哨兵） | info | 正 0/0；注入"通过绿条"后翻红（防串页） |
| `layout_c1_flex_row` | core | 正 182×56 / 262×56 等宽（极差 0） |
| `layout_c2_grid_2x2` | core | 正 2 行 ×2 列、列 x 对齐 |
| `layout_c3_box_model` | viewport | 正 250 宽 / 跨距 145(+5px 边框)=150 |
| `layout_verdict_pass` | viewport(min_h=1400) | 正 1483 / 30489；合成高画幅绿条可触发（谓词非恒失败） |
| `interaction_no_blocks` | core | 正：banner 下方唯一色块是 92×34 的按钮（< 阈值 40）→ 跨页鉴别 |
| `interaction_checks_table` | viewport(min_h=420) | 正 9 条 ×29（`min_lines=7` 以排除 index 的 6 条 ×31） |
| `interaction_selfcheck_pass` | input(min_h=1400) | 正（点击后）1899 / 60056；未点击 0 / 36 |

### 4.1 三重对照（`ppm_assert_selftest.py`）

```
1. 正对照     6/6   三页 × 两画幅，严格集全绿（7/7、7/7、5/5、4/4、4/4、4/4）
2. 跨页负对照 12/12 每页 × 其它两页 profile，严格集必须失败
3. 合成负对照 7/7   全白 / 涂白一块 / 黄块下移 / 抹掉 3 条横线 /
                    注入「未通过」红条 / 注入「通过」绿条（串页哨兵）/ 高画幅绿条可触发
4. 真实负对照 3/3   2026-09-21 T490 历史 screendump → 三个 profile 全部失败
─────────────────────────────────────────────
合计 28/28 符合预期（真实负对照每多取一张图就多 3 项；取 3 张时合计 34/34）
```

自检脚本**当场抓到两个真缺陷**（都已修）：

- `index_blocks_equal_width` 在**全白图**上通过 —— 未检出的块宽度为 0，`0,0,0,0` 的
  极差 0 ≤ 4 被判成"等宽"。修法：`ok4 and …` 前置守卫 + 无效块统一归一化为 0 尺寸
  （原先会打印 `w = -1073741824` 这种哨兵值）。
- 破坏方式本身写错了：第一版"把黄块下移 25px"平移的是**整条行带**，四块一起动，
  "同行"关系毫发无损 → 对照组白跑一轮。修法：按**矩形**平移，并把这个教训写进函数注释。

`PAGE_URL` 白名单另有一个**靠"完整校验链"才暴露的洞**（第三个真缺陷）：

```
file:///usr/share/html-test/../layout.html
  形式校验  通过（* 能覆盖 ..）
  入口名校验 通过（entry = layout.html，字符合法）
  在页面集内 通过（layout.html 确实在集内）
  → 但该 URL 实际解析到 /usr/layout.html（不存在）⇒ 整轮"声称测 layout 页、实际加载 404"
```

修法：校验链最前面加一道 `*..*` 拒绝。修后复验：正常 URL 放行，`../x.html`、
`../layout.html`、`file:///evil/x.html`、带尾空格的 URL 全部拒绝。

## 6. 五条工程发现（会直接影响后续轮次设计）

1. **`layout.html` 的关键结论在首屏之外**：整页 y≈1450 处才是"6/6 通过"结论条，
   1280×800 的 screendump 看不到（实测只剩 30 px 噪声绿字）。C1/C2 网格在两种画幅下都在
   首屏内，因此"CSS 布局是否正确"可以直接用首屏证明，但**结论条需要更高窗口或滚动**。
   窗口高度与滚动方式属"一轮一变量"，下一轮单独定标。
2. **`interaction.html` 的 A 段自检必须有一次真实点击**，B 段还要真实键盘输入与鼠标点击
   （键入回显、点击 +1、链接跳转）。也就是说：**键鼠输入链路从"诊断项"升级为决赛功能项的
   刚需**。当前 guest 侧 `/dev/input` 只有键盘（G6：第二台 virtio-input 被丢弃），
   这直接卡住"JS 交互测试页"的自动取证 —— G6 的优先级应再上调。
3. **官方 `index.html` 是无脚本静态页**，对它做双帧差分必然 0 差异（页面自己写明
   "无时间依赖，截图结果应逐队一致"）。JS/渲染存活的像素证据改看**结论条颜色**
   （`#dafbe1` 绿底 + `#1a7f37` 绿字），正负分离度 >1000 倍（60056 vs 36）。
4. **表格线判据不能按屏宽取阈值**：1280 画幅下内容被 `max-width:880` 截断，
   "≥0.28·W" 会 0 命中。已改判"等长 + 等间距自洽"。
5. **同色多元素必须分带**：不使用行带投影而直接取整体 bbox，会把 banner 判据毁成
   848×692 的噪声框。

## 7. 复现命令

```bash
# 1) 参考渲染（三页 × 两画幅）
for page in index interaction layout; do for wh in 1280,800 640,480; do
  "/c/Program Files/Google/Chrome/Application/chrome.exe" --headless=new --disable-gpu \
    --hide-scrollbars --force-device-scale-factor=1 --virtual-time-budget=2500 \
    --window-size=$wh --screenshot="$PWD/scripts/testpage/reference/ref-official-$page-${wh/,/x}.png" \
    "file:///$PWD/scripts/testpage/$page.html"

# 2) PNG → PPM（判据只吃 P6）
python3 scripts/png2ppm.py --out-dir tmp/ref-ppm scripts/testpage/reference/ref-official-*.png

# 3) 单图判据
python3 scripts/t490/ppm_assert.py tmp/ref-ppm/ref-official-index-640x480.ppm \
    --profile official-index --strict --json tmp/index-640.json

# 4) 三重对照自检（28 项）
python3 scripts/t490/ppm_assert_selftest.py --refs 'tmp/ref-ppm/ref-official-*.ppm' \
    --real 'evidence/2026-09-21_t490-*/screenshots/*.ppm' --json tmp/selftest.json

# 5) 注入器干跑（本机，无需镜像）
bash scripts/t490/t490_inject_pages_dryrun.sh        # 期望末行 INJECTOR_DRYRUN_OK
#    （Windows 上若被沙箱 SIGTERM，改由 python 驱动：
#     python3 -c "import subprocess;subprocess.run(['bash','scripts/t490/t490_inject_pages_dryrun.sh'])"

# 5b) 几何测量（新页面集到来时重新取常量）
python3 scripts/t490/page_measure.py tmp/ref-ppm/ref-official-index-640x480.ppm
python3 scripts/t490/page_measure.py --bands tmp/ref-ppm/ref-official-layout-1280x800.ppm

# 6) 真实一轮（T490）

  bash ~/xk6/scripts/t490/t490_round.sh official-1 600 120 autorun_v5.sh
```
