# T490进程树采样器 guest smoke R1：root进程未发现（2026-11-20）

## 结果

为补齐RSS/PSS/USS秒级采集，新增C语言静态guest采样器原型。T490 native Linux父子进程烟测得到4个时间点、2个进程和有效的RSS/PSS/USS数值；AArch64 musl静态编译也通过。但把目标二进制注入2 GiB AArch64纯TCG guest后，R1没有发现指定root进程，输出 `samples=0 processes=0` 并按失败退出。因此当前没有任何x-kernel或Chromium进程树内存有效样本。

本轮没有启动Chromium，也不计入正式稳定性或性能样本。现存证据不足以确定root未发现的具体procfs字段原因；R2加入原始root `/proc/<pid>/stat` 和进程列表诊断，并单独确认starttime为0时的处理。
