# T490 2 GiB 输入尝试 R16：计数坐标和 Home 截图修正前 ready 再次超时

## 结论

R16 使用 step3、计数候选坐标 `(212,638)`、CSS 链接 `(350,710)`，并计划在导航后发送 Home 取页面顶部 strict 截图；但页面在 2,000 秒 ready timeout 前没有通过 `official-interaction` strict gate，所以这些交互修正均未执行、尚无验证结果。Readiness 共保存 187 张 PPM 判据，最后一帧仍缺 official banner 与 interaction checks 表；26 张正式 QEMU screendump 全部 strict 失败。

新增的 QMP timeout 早退已再次验证成功：`QMP_TIMEOUT_QUIT_RC=0`，QEMU 实际运行 2,003.9 秒后停止，未继续跑完 2,400 秒计划。输入 driver 未启动，EVDEV_PROBE=0，因此本轮没有键鼠动作或 event node 事件结果。Input 仍为 0/4，2 GiB 总分保持 16/20。

R16 是无 observer ready 长尾的又一次观测，说明交互页 cold-start 本身仍不稳定；它不能用来判定 step3 坐标或 Home 截图是否有效。内核工作树仍 dirty，本轮不作为正式性能样本。
