# T490 2 GiB 输入尝试 R22：counter ROI 光标假阳性

## 结论

R22 的 as-run gate 将 mouse counter 判为 PASS，但 after-click 截图仍显示 counter 为 0。逐像素复核发现，旧 ROI `220,625,600,655` 内的 42 个变化像素是光标形状，bbox `[293,629,300,643]`；它们与计数数字无关。把同一组 T490 原始帧改用数字专用 ROI `555,625,570,650` 复算，只有 0 个变化像素，counter gate 应为 FAIL。

driver 因旧 ROI 的假 PASS 在第一个 counter attempt 后停止，没有执行 `INTERACTION_COUNTER_RETRY_TARGETS` 的备用点。R22 的 CSS 导航 strict gate 也为 FAIL，after-navigation 截图仍显示 interaction 页，counter 仍为 0，Input 仍 0/4。R23 将使用新 digit-only ROI，使 fallback 只在数字确实未变时执行。
