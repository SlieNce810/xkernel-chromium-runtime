# T490 R70：a70e compatibility 候选正式稳定性通过

R70 是 c80/a70e candidate 上的正式 stability gate。2 GiB AArch64 pure TCG，Chromium 149.0.7827.53；QEMU `-kernel` 指向 `/home/mo/xk6/worktrees/r64-targeted-scm-no-direct`，实际/预期 SHA 均为 `a70ecb4a34910f56c31d677f1b27d3a25088b94dc2fc82ba13b33544f34e3c1f`。

结果：首屏 official-index strict PASS；真实 QMP Ctrl+R reload 10/10 strict PASS；通过首屏后保持 1804.991 秒；60 点 host QEMU liveness；0 个进程退出、未分类退出或 guest exceptions；事件 normalizer 974/974 PASS、0 修复。正式 gate、driver、round、normalizer rc 都是 0。完整证据见 [R70 evidence](../evidence/2026-11-22_t490-r70-r64-compat-formal-lowshot/README.md)。

R70 的 `IVL=1200` 与 R54 通过设置的周期截图间隔一致，process scan 30 秒、family watchdog 15 秒。R69 以 `IVL=30` 正式尝试首屏超时；R70 成功。这一对结果表明周期 screendump 负载可能影响首屏，但每种配置各一轮，仍不能下因果结论。

R65、R66、R68 在相同 a70e binary hash 下提供三次短诊断冷启动通过；R67 同 hash 在 2400 秒内超时。R70 另提供正式长稳定性通过，所以稳定性完成标准已有正式候选证据，但间歇失败仍如实保留。该轮没有 memory/lifecycle sampler，因此四项性能数据仍无有效样本。
