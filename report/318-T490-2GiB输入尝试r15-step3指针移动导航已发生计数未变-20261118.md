# T490 2 GiB 输入尝试 R15：step3 相对移动导航已发生，计数未变

## 结论

R15 使用 `INTERACTION_POINTER_MODE=step3`（每次 3 像素、20 ms 间隔）和 `INPUT_NAVIGATION_WAIT=60`。页面在第 46 次 readiness 采样通过；10 秒键盘 echo 轮询通过，JS self-test 6/6。驱动执行了 20 个键盘动作、5 次 HMP 点击和 679 次相对移动。

R15 的 `after-mouse-navigation.png` 已显示 CSS `layout.html` 页面内容，说明导航操作实际发生；strict layout 子 gate 仍失败，因为导航后保留了滚动位置，official banner、C1/C2/C3 没有进入当前 viewport。下一轮会在导航等待后发送真实 Home 键，把页面滚到顶部再保存 strict 判据。

计数仍为 0。`after-mouse-click.png` 中光标出现在 CSS 链接附近，而不是计数按钮；这表明 step3 请求计数按钮 `(281,674)` 时相对指针偏移约为右下 `(69,36)`。下一轮计数点击目标候选修正为 `(212,638)`，导航目标保持 `(350,710)`。本轮没有 evdev observer，鼠标 event 节点数据未采集。Input 仍为 0/4，2 GiB 总分保持 16/20。

step3 没有触发 R14 的 Page Unresponsive 画面；它比 step1 的 2,021 次移动更少（本轮 679 次），页面维持响应并完成 CSS 导航。该差异是实验观察，仍需用校正后的计数点击复验。
