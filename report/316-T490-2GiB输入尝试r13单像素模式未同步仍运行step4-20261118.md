# T490 2 GiB 输入尝试 R13：step1 模式未同步，实际仍运行 step4

## 结论

R13 launcher 请求 `INTERACTION_POINTER_MODE=step1`，但 T490 上的 `run_input_final.sh` 仍硬编码 `INTERACTION_POINTER_MODE=step4`。QMP 输入 ledger 明确记录 `pointer_mode="step4"`，移动总数也与 step4 一致；所以这轮没有验证单像素步进，结果必须按 step4 复测记录。

ready 第 49 次采样通过；JS 自检和 keyboard echo 通过，driver 记录 20 个键、5 次点击、453 次 HMP 相对移动。计数和 CSS 导航仍未通过，Input 仍为 0/4。QMP quit rc=0，实际会话 762.6 秒结束。

检查发现仓库脚本已经支持环境变量覆盖，T490 副本却没有同步：仓库规范化内容 SHA-256 是 `44a93c67bda82f78b7057bc75587237243ba7b5d3f5ddd3d5db12e41f64eb4a0`；R13 T490 实际文件 SHA-256 是 `ac50ad535ea383cda08e54a5ecbfb333eaf0947d014079f48227fa6b51669c01`，且其中仍为 `INTERACTION_POINTER_MODE=step4`。下一轮会同步 runner 并在启动前比对 SHA-256，再跑真正的 step1 模式。
