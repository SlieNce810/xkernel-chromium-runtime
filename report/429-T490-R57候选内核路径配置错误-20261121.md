# T490 R57 候选内核路径配置错误

## 结论

R57 不构成 no-direct-PTE ERROR 候选的启动样本。虽然外层 shell 在候选 worktree 内运行，`run_stability_round_mp.sh` 没有将该路径传给 `t490_round.sh`。后者按默认值使用 `/home/mo/x-kernel`。

证据显示实际 QEMU `-kernel` 为 `/home/mo/x-kernel/target/xkmake/kplat-aarch64/release/kernel.bin`，SHA-256 为 `51c4028594e4aff9fc5b9964c4294a2904621c93e84093ac711858c454aed284`。目标候选的 SHA-256 为 `c78ecd57fb47b8269ebecf0a4e99ee5d9f85648e01703726eee7af88ad017a67`。两者不同。

发现问题后已停止 R57。会话约运行 190 秒；没有严格页面通过、重载或保持结果，稳定性驱动以 `Broken pipe` 结束。此轮仅作为配置错误记录，不参与候选冷启动/稳定性统计。

## 修复

更新 `scripts/t490/run_stability_round_mp.sh`：

- 解析并导出 `KERNEL_DIR`，供 `t490_round.sh` 和 `run_session_t490.sh` 使用；
- 在 dry-run 和证据配置中显示内核工作树、内核文件及 SHA-256；
- 支持 `STABILITY_EXPECTED_KERNEL_SHA256`，并在 QEMU 启动前拒绝哈希不匹配；
- 将选中的内核路径和哈希写入每轮 `stability-run-config.txt`。

后续候选复测会显式设置 `KERNEL_DIR=/home/mo/xk6/worktrees/r53-no-direct-error-log` 和预期 SHA-256，并先检查干跑输出中的路径和哈希。
