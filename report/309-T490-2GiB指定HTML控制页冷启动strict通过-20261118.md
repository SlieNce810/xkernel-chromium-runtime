# T490 2 GiB 指定 HTML 控制页：独立冷启动 strict 通过

## 结论

为区分 R5 的 `interaction.html` ready timeout 是普遍冷启动问题还是交互页特有问题，我在同一 T490、同一 2 GiB AArch64 纯 TCG、同一 Chromium 149 镜像下，单独冷启动官方 `index.html`。该控制轮在 guest 480 秒的第 5 张截图通过 `official-index` strict 7/7；随后至 700 秒 final frame 持续通过。T490 远端 `score-page-gate.json` 为 `pass=true`、`round_rc=0`，9 张截图中 5 张通过，前 4 张是 strict warmup 失败。

因此，R5 的 2,000 秒交互页空白现象没有复现到指定 HTML 控制页。现有证据把诊断范围收窄到 `interaction.html` 的加载、renderer 提交或页面特有 JS 路径；这是对两轮结果的推断，根因仍未确认。浏览器功能得分仍为 16/20，Input 4 分尚未通过。
