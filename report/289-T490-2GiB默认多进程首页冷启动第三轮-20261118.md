## 进程事件门禁修复与证据

第一次运行时，score wrapper 的原始 process gate 返回 rc=1。console 中 Browser 的第一条 MP_EVENT 被截断在 timestamp/role/PID/PPID 后，导致原始 JSONL 解析失败。邻近的 MP_PROCESS_OBSERVED 记录保留了相同 role/PID/PPID；随后 renderer 事件 JSON 完整。

新增的归一化器只在这四项原始值严格对应时补齐 observer 的固定 schema 字段，并将补出的事件标记为 console_reconstructed。它不修改原始 console，也不把该归一化事件用作性能样本。归一化器输出 10 条进程事件、重建 1 条 Browser 事件；严格父链复核和原始命令参数检查均通过。其他候选 PID 与未匹配 Zygote 的组合保留在 alternate_parent_link_mismatches 中，不覆盖已验证的 PID 链。

- 原始 run 的 `process-structure-gate.json` 保留外层失败 rc=1。
- 修正后的归一化文件、summary、strict gate 输出见 [`cold03 review`](../evidence/2026-11-18_t490-goal2g-index-cold03-review/)。
- 统一入口 score-process 复核结果见 [`cold03 score-process recheck`](../evidence/2026-11-18_wsl2-cold03-score-process-recheck/)，`acceptance.json` 为 `overall_rc=0`、`score-process=0`、4/20 points。
- 页面 gate 与全部逐帧断言见 [`cold03 evidence`](../evidence/2026-11-18_t490-goal2g-index-cold03/)；原始 PPM 保留在 T490，SHA-256 清单见 [PPM manifest](../evidence/_ppm-sha256-2026-11-18_t490-goal2g-index-cold03.txt)。该轮的 `score-page-round.log` 为 0 字节；原始 `console.log`、`cmd.txt` 和 gate JSON 是完整运行记录，当前补丁已让后续轮次在 round log 中写入外层 gate 状态。

## 验收边界

本轮只覆盖指定静态首页和默认进程父链。它没有完成双页签、真实键鼠应用回显、JavaScript、CSS 等其余功能复验。总时长 1803.3 秒，首个 strict 页面在 420.8 秒通过，strict 通过后剩余约 1382.5 秒，短于“从首个页面 PASS 起再稳定运行 1800 秒”的口径；本轮也没有十次真实重载。因此不能计为稳定性 PASS。

性能事件、真实 RSS/PSS/USS、四指标有效样本和优化前后各五轮仍未完成。`MP_RSS_KB=0` 不作为内存证据；原生 sandbox 也没有验证。
