## 验收边界

此轮只验证指定静态首页。它没有从首个严格帧之后继续运行 30 分钟，也没有进行十次真实导航；它不提供 Browser → Zygote → Renderer 父链门禁结果、真实输入或其余五项功能结果。QEMU 约 1803.5 秒的总时长短于“首个 strict 页面通过后再保持 1800 秒”的稳定性口径。`MP_RSS_KB=0` 不构成任何内存指标样本；PSS/USS、四项有效性能样本及 before/after 优化结论仍未完成。

下一轮使用 `autorun_mp_score_observe6.sh` 与 `PROCESS_STRUCTURE_GATE=1`，同时验证首页 strict gate 和 Browser → Zygote → Renderer 直接父链；运行后再启动独立稳定性会话。
