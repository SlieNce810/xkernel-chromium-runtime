# T490 · 2 GiB 默认多进程首页冷启动首轮（2026-11-17）

## 边界

这轮证明了指定 HTML 在 2 GiB 下可通过严格判据，但不能计为 30 分钟稳定性 PASS：稳定性计时必须从 481 秒的首个严格页面帧之后开始，本轮总时长只有 1804.3 秒，且没有每两分钟的真实导航/重载流程。运行时 `MP_LEDGER_VALUE=0`，因此本轮也不作为 Browser/Zygote/Renderer 每 30 秒存活记录。`MP_RSS_KB=0` 是旧 observer 读 `/proc/<pid>/stat` 得到的不可用标记；本轮不提供 RSS/PSS/USS 性能数据。

Chromium argv 未使用 `--single-process` 或 `--no-zygote`，但本轮的 HTML 页面 gate 不替代进程父链 gate，也不能单独把这次 run 记作完整的 20 分复验。实际 argv 记录在 `console.log` 的 `CHROMIUM_EXEC_ARGS` 行；sandbox 仍是 `--no-sandbox` 诊断模式。

该目录记录的是 2 GiB 首页复验的 cold01；cold02、cold03 已分别在 [report 288](288-T490-2GiB默认多进程首页冷启动第二轮-20261117.md) 和 [report 289](289-T490-2GiB默认多进程首页冷启动第三轮-20261118.md) 留证，首页冷启动目前 3/3 通过。cold03 的进程父链复核也已通过，原始外层 gate 因 console 截断返回失败，复核过程见 report 289。下一步运行专用 QMP 稳定性入口，从首页严格 PASS 起计时 30 分钟，按两分钟间隔执行十次真实 Ctrl+R，并检查 guest 进程账本。
