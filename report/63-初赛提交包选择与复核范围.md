# 初赛提交包选择与复核范围

提交包由材料分支冻结提交、经过哈希校验的证据原件和本地已验资产组成；具体目录见 63-submission-package-selection.json。生成包时重验每个文件 SHA-256，写入 submission-manifest.csv 和 SHA256SUMS，再测试 ZIP CRC 与包内逐文件哈希。外层 ZIP 的独立哈希清单和汇总文件置于同目录。报名表按用户要求跳过；仓库中未找到组委会最终材料模板、学校盖章页或技术主体身份页，因此包内不伪造或声明这些附件已完成。赛题 PDF 第 3 页列有初赛提交技术方案、代码仓库、构建配置、自动化测试脚本、运行日志和演示视频，未在该清单列出盖章/身份页；本地文件为 [赛题六 PDF](../docs/报名资料/附件2：第三届“中国电子杯”高校ICT产教融合创新大赛命题/6%20赛题六：先进计算应用赛道-基于x-kernel的Chromium运行环境构建与优化%28麒麟软件有限公司%29.pdf)。

Git 提交只保存代码、报告、来源/回收清单和原件哈希清单；65 张新增 PPM 随交付 ZIP 提供，不加入 Git 历史。包内保留控制截图、失败样本、before/after 原始数据、T490 日志、guest 输出，以及来源内核的独立源码归档；失败轮不改写为 PASS。

| 项目 | 复核依据 |
|---|---|
| 原件 | 65 张回传 PPM；两份 console；录制轮 12 份 guest 文件；逐文件清单、SHA 和内容关联 |
| 缺口附件 | 八条现象、复现与 Linux/guest 输出、补丁/限制；探针未覆盖的协议分支和硬件输入链 |
| 性能对照 | before/after 各五轮，统一 PI 中和适配器、页面、内核参数、镜像和测量脚本；raw CSV、截图及波动范围；四项性能指标均未达 5% 改善档位，详见 [report/64](64-共同用户态适配器before-after五轮实测.md) |
| 首帧测量 | 首张严格通过的 1280×800 QEMU screendump，截图间隔 15 秒；先前未通过帧保留 |
| 干净 Linux 复现 | WSL2 Ubuntu 22.04、QEMU 8.2.3 pure TCG、Rust 1.95，从交付 ZIP 解压代码与资产，使用独立 HOME、源码 checkout、target 和工作盘 |

共同 PI 回退用于让首个版本与当前内核都能启动同一页面；它改变用户态互斥量属性，不实现内核 PI。性能改善档位依据统一原始数据计算；若中位数改善低于评分门槛，不以失败/可用两状态换算百分比。


共同适配器组的五个有效样本来自 before 原始采集目录及 after 原始采集、重试目录；after 失败轮和重试全过程均保留。报告 57 的未适配器 before 五轮失败是另一运行条件，不能与共同适配器数据混合。fdprobe 首次原生宿主测试对两个固定 /tmp 路径使用 O_TRUNC 的已知副作用及无法确认的先前状态，见 report/60。
