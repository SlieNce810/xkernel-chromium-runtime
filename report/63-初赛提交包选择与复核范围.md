# 初赛交付范围

2026-10-14 按用户要求收敛为最小 T490 交付，正式入口为 `submission/README.md`、`submission/技术方案.md`、`submission/证据说明.md`。唯一生效白名单是 `submission/selection.json`，由 `tools/package_minimal_submission.py` 从冻结提交导出。

WSL2 仅用于测试验证，相关脚本、证据、操作说明及报告不进入初赛提交；Windows 本机辅助脚本同样排除。交付一份整理后的 T490 原始证据集、一份完整录像、必要源码/配置与运行脚本。旧版 ZIP 与旧选择 JSON 属研究归档，不再作为正式交付入口。

包内 `manifest.csv` 保留原件来源和逐文件 SHA-256；原始日志不改写。首次历史 baseline 和后续 PI 适配器研究不与当前原始栈五次观测混用，性能不申请改善百分比。报名表按用户要求跳过。
