# T490 2 GiB 输入尝试 R19：两点外推指针落至屏幕外

## 结论

R19 在 T490 上以 2 GiB guest、AArch64 纯 TCG 和 Chromium 149 默认多进程运行。交互页在第 45 次 readiness 采样通过；JavaScript 自检和键盘回显通过。鼠标计数仍为 0，CSS 链接没有打开布局页，Input 仍为 0/4，总分仍为 16/20。

本轮用 R17/R18 两次截图热点建立的线性外推，请求计数 `(233,1138)`、CSS `(287,778)`。原始 PPM 的 `after-scroll` 与 `after-mouse-click` 差分仅改动 4 个像素，变化框为 `[250,799,693,799]`，都贴在画面最底行；没有检测到完整的在屏光标形状。计数保持 0。导航后的截图仍显示 interaction 页面；随后 3 次 PageUp 把该页滚回顶部，但 CSS strict 判据没有通过，因为 CSS 页面从未打开。

R17/R18 的两点外推不能预测更大相对输入值的落点，R19 已作为模型失效的反例归档。R20 应在已观察的步进范围内调整计数 Y 请求，并使用曾打开过布局页的 CSS 请求 `(350,710)` 作导航基准；仍需以屏幕截图与门禁验证，不视为已校准。
