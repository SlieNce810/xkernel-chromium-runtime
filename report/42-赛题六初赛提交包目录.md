## 证据和复现

- 主流程、JS/CSS、演示录屏、历史单进程测量和所有必要的原始 evidence 目录均由 report/63-submission-package-selection.json 精确选择。
- 新回收的 65 张 PPM 随提交 ZIP 交付，遵守仓库约定，不加入 Git 历史；逐文件哈希同时进入包内 submission-manifest.csv 与 SHA256SUMS。
- before 与 after 各有五个 gate/官方像素断言通过的共同适配器样本。原始失败轮和重试尝试保留；after 配对 CSV 是单独筛选的新文件，原始 raw.csv 未改写。
- T490 使用共同 PI 中和 preload 才能让首个 tag 与当前内核在同一页面完成比较。该 preload 改变用户态 pthread mutex 协议，不实现内核 PI；性能数据不等价于未适配器正常运行。
- clean Linux reproduction 按交付 ZIP 解压后在独立 WSL2 Ubuntu 22.04 HOME/源码 checkout/工作盘运行；结果以 report/62 及本次验证证据为准。该环境与 T490 是两种 Linux 目录，不宣称是第二台物理主机。
