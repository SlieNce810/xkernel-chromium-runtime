# T490 R25 lifecycle 快路径与采样窗复测（2026-11-21）

## 结论

R25 使用冻结的 AArch64 2 GiB pure-TCG worktree 与新版 `lifecycle_event_preload.c`。官方首页首载 strict、1/1 真实 Ctrl+R 重载和 420 秒诊断保持均通过；driver 记录 `pass=1`，watchdog 在结束前持续观察到 Weston/Chrome。首页首次 strict 截图的 guest 单调时钟保守上界是 `651.566874801 s`，QMP 采样间隔为 30 秒。以 Browser 启动请求 `42.821946208 s` 为起点，该截图上界为启动后 `608.745 s`。

R25 **不是有效四指标样本**。保持段结束时 QMP 关闭 QEMU，1200 秒内存 sampler 尚未到请求终点，最终没有 `memory-export` 或 lifecycle preload 事件文件；`collect_metrics.py` 因没有 Browser root 事件而拒绝样本。导航请求、renderer-ready、first-valid-frame、RSS/PSS/USS 峰值均标记为不可用。截图通过和进程观察不能替代这些生命周期或内存数据。

| 项目 | R25 观测 |

| QMP 首页 strict 首次通过 | `ready_elapsed_ms=651106.830664` |

| 画面采样间隔 | 30,000 ms |
| 真实重载 | 1/1 strict PASS |
| 诊断保持 | 420 s，`STABILITY_DRIVER_RESULT pass=1` |

guest-clock 映射只把 QMP strict screenshot/verdict 映射到相邻 clock-sync 锚点；串口接收延迟未单独测量，因此该截图时间只作为保守上界。归档的 [`lifecycle-events.screenshot-upper-bound-v2.jsonl`](../evidence/2026-11-21_t490-r25-lifecycle-fastpath/lifecycle-events.screenshot-upper-bound-v2.jsonl) 仅含 QMP 截图与 verdict 两条事件，summary 保持 `valid=false`，没有补造浏览器、renderer 或导航事件。

R25 与 R23 的首页 strict elapsed 分别为 651.107 s 与 987.609 s，但 R23/R25 没有导出完整同口径事件和内存样本，也没有重复配对；该差值仅作为后续复测线索，不归因于 preload 快路径，不列为已验证性能收益。

## 采样窗与下一轮

本轮 sampler 请求 1200 秒；QMP 在 420 秒保持结束时关闭 guest，因而超过实际会话末端的样本窗口没有完成。按 R25 页面通过时序，下一轮改为 900 秒 sampler：窗口从 Browser 启动附近开始，预期仍覆盖 strict 页面上界后至少 60 秒，并可先于同一 420 秒保持结束，以便验证 sampler 正常收尾及 lifecycle 文件导出。若页面时序变化使该覆盖条件不成立，下一轮仍只作为诊断，不接受峰值统计。
