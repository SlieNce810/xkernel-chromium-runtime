# Chromium 149 兼容性矩阵与补丁索引（2026-11-17）

## 结论范围

本报告把历史 Linux 对照、x-kernel 失败复现、补丁和 Chromium 回归分开记录。底层 ABI 探针通过只证明该接口用例符合 Linux；除明确写有页面回归外，不把探针通过等同于浏览器页面通过。

当前用于本轮 2 GiB 复验的 T490 快照见 [baseline freeze r3](../evidence/2026-11-17_t490-goal-baseline-freeze-r3/baseline.json)：Chromium 149.0.7827.53、QEMU 10.2.1、AArch64、纯 TCG、`MEM=2g`。kernel commit 是 `b73e5814087c9d33c5f0a35b66cc56be689d3dee`，binary SHA-256 为 `51c4028594e4aff9fc5b9964c4294a2904621c93e84093ac711858c454aed284`；工作树有未提交改动，因此它适合作为本次功能复验快照，不能直接作为性能比较的干净 tag。

## 2026-11-19 WSL2 参考补充

`compatprobe.c --inotify-timerfd` 已在 WSL2 Linux 5.15.167.4 / x86_64 上通过 11/11 个基础行为检查；此后同一完整 C probe 在最终候选 `ba202fdd…` guest 也通过。Chromium watcher 的 7 次 `NotFound` 路径诊断与 Linux `FilePathWatcher` best-effort 行为一致，见 [report 341](341-Chromium149-inotify可选路径NotFound分类-20261119.md) 和 [report 342](342-T490同一候选内核memfd与madvise兼容性修复-20261119.md)。

同源 probe 的 `--scm-rights-shortread` 在该 WSL2 Linux 上通过 6/6，且在最终候选 guest 通过 6/6；fd 在首个 1-byte `recvmsg` 到达，之后不重复，100-byte payload 完整，见 [report 328](328-SCM_RIGHTS-stream-shortread-WSL2-Linux基线与T490待补-20261119.md) 和 [report 342](342-T490同一候选内核memfd与madvise兼容性修复-20261119.md)。

`procfs_memory_probe.c` 已在 WSL2 Linux 参考分配/触页、私有文件、共享映射、fork/COW 与 unmap，`smaps_rollup` 读到有效 RSS/PSS/USS；同轮 status/statm 在触页早期的 RSS 值较滞后。该 probe 是诊断参考，不是 Chromium 树样本，且不能替代 T490 native/x-kernel 同 hash 对照，详见 [report 330](330-procfs-memory-WSL2-reference-and-T490-followup-20261119.md)。
3. 兼容性修复报告中的页面白屏结果仍是失败结果。任何 ABI 探针通过都不能覆盖默认多进程 HTML 的严格像素 gate。

## 2026-11-19 候选内核 Chromium 集成复核

候选内核在 2 GiB pure-TCG 默认多进程 Chromium 149 中通过指定 HTML strict gate；实际 console 记录 SCM_RIGHTS fd 接收，Browser → Zygote → Renderer 严格父链经归一化修复后通过。同一内核 SHA `fa02114a…` 的 inotify/timerfd、SCM short-read、RSS/PSS/USS COW/unmap probe 均通过。7 次 `inotify_add_watch NotFound` 是可选 policy/time-zone 路径；7 次 `memfd_create` raw flags=`0xffffffff` 与原生 Linux `EINVAL` 一致。随后在 [report 342](342-T490同一候选内核memfd与madvise兼容性修复-20261119.md) 记录了 sealing 与 madvise gap 的真实缺陷及修复；最终候选 `ba202fdd…` focused matrix 38/38、memfd seal 12/12、memspace unit tests 14/14。该最终 hash 的 Chromium 页面集成仍待复验。
